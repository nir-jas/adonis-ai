# Security policy

## Supported versions

During the pre-1.0 period, only the latest published prerelease receives security fixes.

| Version                 | Supported |
| ----------------------- | --------- |
| Latest `0.x` prerelease | Yes       |
| Older prereleases       | No        |

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately through [GitHub Security Advisories](https://github.com/nir-jas/adonis-ai/security/advisories/new).

Include reproduction steps, affected versions, potential impact, and any known mitigations. Remove API keys, credentials, and sensitive prompt or provider content from the report.
