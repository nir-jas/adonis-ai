# Support

Use the channel that best matches the request:

- Ask usage, integration, and API-design questions in [GitHub Discussions](https://github.com/nir-jas/adonis-ai/discussions).
- Report reproducible bugs and request actionable features through [GitHub Issues](https://github.com/nir-jas/adonis-ai/issues).
- Report suspected vulnerabilities privately through [GitHub Security Advisories](https://github.com/nir-jas/adonis-ai/security/advisories/new).

When asking for help, include the Adonis AI, AdonisJS, and Node.js versions; the provider in use; a minimal reproduction; and sanitized errors or logs. Never share API keys or sensitive prompt content.

Support is community-based and response times are not guaranteed.
